如何理解证据等级与地区信息？

疑似命中仅有 CF 特征；Trace 有效需要 HTTP 200、正文关键字段及域名一致；双域名确认需要两个 SNI 都通过 Trace 检查。旧版结果需复测后按新标准确认。这些证据不能单独证明 Reality 回落。

请求耗时包含连接、TLS 握手与 HTTP 读取，鼠标停留可查看分阶段时间。CF 出口地区与响应机房不能代表目标 VPS 的实际位置。历次命中率按保存的观测计算，旧版记录不补造历史时间。
