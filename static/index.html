ASN 公告前缀是可选目标来源，不保证覆盖该服务商全部产品或地区。缓存更新失败时保留上次成功记录；大服务商可分批选择网段，单任务仍最多 200 万个 IP:端口。

如何理解证据等级与地区信息？

疑似命中仅有 CF 特征；Trace 有效需要 HTTP 200、正文关键字段及域名一致；双域名确认需要两个 SNI 都通过 Trace 检查。旧版结果需复测后按新标准确认。这些证据不能单独证明 Reality 回落。

请求耗时包含连接、TLS 握手与 HTTP 读取，鼠标停留可查看分阶段时间。CF 出口地区与响应机房不能代表目标 VPS 的实际位置。任务完成后仅保留命中记录；历史统计显示命中与双域名确认次数，旧版记录不补造历史时间。
